# AI 新闻台设计规格

## 信息架构

- 左侧主导航：今日工作台、草稿箱、新闻源、定时任务、运行记录。
- 主流程固定为：采集 → 筛选 → 成稿 → 填入编辑器。
- 工作台采用“配置带 + 候选新闻表格 + 本次运行状态轨”的开放式布局，不使用卡片网格。
- 草稿页采用“草稿列表 + 图文编辑器 + 来源与配图检查器”的三栏布局。
- 最终动作只允许“填入小黑盒”，不提供自动点击发布。

## 视觉令牌

- 主背景：纯白 `#ffffff`。
- 导航背景：暖纸色 `#faf8f4`。
- 主文字：炭黑 `#202124`；次要文字 `#6f7278`。
- 细分隔线：冷灰 `#dedfe2`；悬停底色 `#f7f7f8`。
- 主强调色：朱红 `#e6322b`；浅强调底色 `#fff3f1`。
- 成功色：`#18864b`；警告色：`#b86d12`；错误色：`#b42318`。
- 圆角：输入框与按钮 8px，面板 10px；不使用夸张圆角。
- 阴影：仅浮层使用 `0 12px 30px rgba(20, 22, 25, .10)`，常规界面不用阴影。

## 字体与密度

- 中文内容与 UI：`Inter`, `PingFang SC`, `Microsoft YaHei`, system-ui。
- 页面标题：32px/1.2，700；区域标题：18px/1.35，650。
- 正文编辑：17px/1.9，400；表格正文：14px/1.5，400。
- 控件文字：14px/1，500；辅助说明：12px/1.5，400。
- 主导航 214px；运行状态轨 214px；草稿列表 264px；检查器 350px。

## 组件家族

- `AppShell`：左侧导航、页头、主内容。
- `WorkflowStepper`：四阶段及完成/进行/等待状态。
- `CollectionControls`：时间窗、心跳时间、成稿模式、图片规则、新闻源选择。
- `CandidateTable`：勾选、价值分、来源、标题、发布时间、证据、原图。
- `RunRail`：真实任务阶段、错误和最近产物。
- `DraftEditor`：标题、短段落、段间来源图、末段判断；所有内容可改。
- `EvidenceInspector`：来源、待确认项、图片选择、社区和话题。
- `SourceManager`、`ScheduleSettings`、`RunHistory`：配置与审计页面。

## 交互约束

- 采集、生成、图片提取、填入均展示真实状态，不用模拟进度。
- 只有至少勾选一条候选新闻时才能生成文章。
- 图片仅允许来源页、官方素材或网页截图；默认不生成图片。
- 每篇文章独立生成；生成后保留 Horizon run ID、候选 ID 和全部原始链接。
- 填入动作不会点击小黑盒最终发布按钮；登录失效、验证码或选择器变化时立即停下并报告。
