# AI 设置与自动化整理

用户否定首页、新闻工作台的第三轮设计，确认继续优化 AI 设置和自动化。本轮将这两页的布局整理落实到 React 组件，其他页面和全局导航保持现版。

## 改动

- AI 设置分为「模型与分工 / Skill 库 / 图片素材库」。四项任务直接选择模型，沿用原有保存回调和可用性限制。接口列表默认展示已配置、本机及当前分工使用的连接，可切换全部；原来每个接口旁重复出现的分工按钮移到顶部。能力说明和费用策略按需展开。
- 自动化分为「采集计划 / 平台连接 / 数据与迁移」。每日与增量计划集中展示，接入现有设置与真实运行记录；技术目录保留独立的读取周期。增量来源存在分别退避的情况，因此未根据一个时间戳虚构统一的下一次运行时间。
- 平台连接默认公众号，可切换知乎／百家号同步助手或小黑盒兼容通道。公众号帮助与环境诊断折叠；既有字段、测试、密钥移除、草稿边界均保留。
- 标签页使用隐藏面板保留组件和表单状态，支持方向键、Home、End。数据占用延迟至进入迁移页时读取；素材图片延迟加载。
- 归档预检、确认令牌、覆盖确认、失败恢复和密钥隔离逻辑未改变。

代码入口：`src/components/AISettingsPage.tsx`、`src/components/SchedulePage.tsx`、`src/components/SettingsTabs.tsx`；样式只作用于设置页，由 `src/main.tsx` 引入 `src/settings-design.css`。

## 验证结果

- `npm test`：1102 / 1102 通过。
- `npm run eval:editorial`：22 / 22 通过。
- `npm run build -- --outDir /tmp/news-desk-settings-build`：类型检查与生产构建通过；输出隔离，未覆盖正式 `dist/`。
- 1440 × 900 桌面与 390 × 844 窄屏检查；页面无整页横向溢出。
- 实际组件中检查任务分工切换、费用锁定不可选、标签键盘操作、素材输入在切换后保留、公众号未保存名称在切换后保留、采集开关与间隔联动、迁移确认按钮在预检前不可见、平台切换只显示相应表单。
- 首轮测试发现组件直接导入 CSS 与 Node 静态渲染测试不兼容，已改为通过主入口加载样式，完整测试重跑通过。
