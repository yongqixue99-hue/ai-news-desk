# 多平台草稿投递第一阶段

## 已实现

文章右侧“发布 → 多平台分发台”增加勾选平台后一次投递。微信使用原有官方草稿 API，小黑盒沿用原有填入助手；新增知乎、百家号的 Wechatsync 浏览器桥接。每个平台独立显示结果，失败不覆盖其他平台的结果。初始只选微信，不自动全选账号。

新增渠道的准备、账号核对、图片上传、版本绑定与回执由 `server/social-delivery.ts` 管理，是 DeliveryDesk 的浏览器渠道实现。素材遵守现有事实和权利门槛，正文图片先校验本机路径与 SHA-256，再转换为 JPEG 并上传目标平台。新增平台授权复选框不会自动扩展已有图片的使用范围。

回执保存在草稿的 `socialDeliveries` 中，包含账号 ID、名称、稿件哈希、时间、远端草稿 ID 和编辑链接，不包含 Token。发送前落盘；断线、超时、进程重启、账号变化、平台未返回完整回执都需人工核对。相同账号和版本复用回执；新版本保留历史并新建远端草稿。未知结果先确认“已核对草稿”或“确认未收到”，不能盲目重试。带新渠道回执的旧稿不会被自动归入隐藏历史。

“助手返回草稿回执”不是内容回读验证，也不是公开发布；用户打开草稿核对后才记录人工确认。本阶段未实现第三方草稿的自动回读或原位更新，未调用最终发布或群发 API。

## 连接方法（Mac / Windows 均需分别完成）

1. 安装 [Wechatsync 文章同步助手](https://www.wechatsync.com/#install)，在同一个 Chrome 登录知乎、百家号。
2. 工作台“自动化”设置页下方的“连接多平台同步助手”填写该助手的扩展 ID。在 `chrome://extensions` 开启开发者模式即可找到。它与工作台现有的小黑盒助手是两个不同扩展。
3. 同步助手设置中开启“同步桥接 / MCP 连接”，服务器地址设置为 `ws://127.0.0.1:19527`，将助手显示的 Token 填到工作台并保存。等待助手连接后刷新登录状态；页面应显示真实账号名称。不要把 Token 发到聊天或写入文件。
4. 打开稿件 → 发布 → 勾选目标 → 一键投递。首次安装、平台登录、验证码与最终公开发布需要用户操作。

工作台独立实现了助手公开 WebSocket 协议，没有复制其 GPL 平台适配器，也不需要安装 CLI。桥接仅监听 `127.0.0.1`，仅允许已配置扩展 Origin，所有请求携带 OS 受保护存储的 Token；不开放外部 HTTP 转发端点。密码和 Cookies 始终由浏览器管理。助手升级可能改变平台能力或协议，需重新验收。

参考源码：[请求处理与认证结果](https://github.com/wechatsync/Wechatsync/blob/v2/packages/extension/src/mcp/client.ts)、[知乎草稿适配器](https://github.com/wechatsync/Wechatsync/blob/v2/packages/core/src/adapters/platforms/zhihu.ts)、[百家号草稿适配器](https://github.com/wechatsync/Wechatsync/blob/v2/packages/core/src/adapters/platforms/baijiahao.ts)。已按实际 `checkAuth` 返回结构使用 `userId`，不能把账号昵称当作唯一标识。

## 微信 AppSecret 在哪里

用公众号管理员微信扫码登录 [微信开发者平台](https://developers.weixin.qq.com/platform/)，在“我的业务（与服务）”中选择公众号／服务号及对应账号，进入“基础信息 → 开发密钥”。根据账号状态点击“启用”或“重置 AppSecret”，完成管理员验证后立即将密钥保存到工作台“微信公众号”设置。若仍是旧版入口，从微信公众平台“设置与开发 → 开发接口管理”进入。

官方平台公开前端（2026-09-20 核查）包含“开发密钥”“启用 AppSecret”“重置 AppSecret”，并明确重置后旧密钥立即失效。若其他工具在使用旧密钥，也需要更新。工作台不会替用户重置。

保存后点击“测试草稿接口”；遇 IP 白名单错误，按提示在微信开发者平台配置当前电脑出口 IP；接口权限不足则需检查账号资格。AppID 与 gh_ 原始 ID 已能本地保存，不能代替 AppSecret。Windows 的 DPAPI 与 Mac 的 Keychain 各自保存，不会随 Git 或数据归档迁移。

## 明确的验收边界

- 知乎／百家号：桥接、账号绑定、图片迁移、草稿请求及回执处理代码已实现。协议模拟和隔离浏览器测试通过后，仍需要安装扩展并登录真实账号，用一篇审定稿做真实草稿验收；不能把模拟回执当作线上成功。
- 今日头条：有后台入口，自动投递保持禁用。公开仓库未提供完整适配器，不能保证其发行包支持草稿且不会触发最终发布。后续先验证实际适配器，再接入。
- 微信：需用户保存 AppSecret、配置白名单并通过草稿接口测试，才能验收真实上传。
- 小黑盒：现有兼容流程保留；本轮没有向真实平台发送测试文章。
- 后续再扩掘金、CSDN、B站文章；小红书等需独立版式适配。
