# 2026-10-02 功能可靠性修复

此次优先处理交付、任务恢复和实际统计，沿用现有编辑界面。公众号仍是主要交付目标；小黑盒为兼容填入，所有公开发布由用户完成。

## 交付核对与恢复

- 微信回读指纹升级到 v2，增加正文段落结构和来源链接地址。平台改过链接或合并段落不能继续被判为发送版本一致；字体、样式包装变化不影响比对。旧 v1 回执保留，并在同版本内容核对后升级。
- 远端写入前，持久化账号、稿件版本、内容指纹、摘要、封面与原稿编号；取得新稿编号后立即持久化。网络丢失更新响应时，下一次先只读核对已知原稿，匹配才恢复回执，避免重复上传、更新或新建。
- 新建请求丢失且没有返回草稿编号时，维持“结果未知”。没有按标题猜测远端文章，也没有新增未验证的查询接口。
- 小黑盒文章正文与发布设置分阶段执行。已完整填入正文和图片时，记录只含哈希、图片编号与远端编辑链接的检查点。重试先回读同一篇草稿；匹配则保留正文图片，续接社区、话题和发布设置。平台内容已被改动时保护平台修改。
- 正文图片只上传了一部分时不形成完整检查点，暂不能保证只补单张图片。封面上传和图文图集仍沿用原流程；不能把文章正文的续接能力泛化到这些步骤。

## 统一多平台任务

现有“草稿 → 交付 → 多平台”支持公众号、小黑盒、百家号、知乎与头条选项。一次保存当前修改，绑定各平台的正文、账号与配置版本，各渠道独立执行并保留结果。明确失败或取消的平台可单独重试；已成功和结果未知的平台不会被批量重试按钮重新发送。旧多平台回执与接口仍保留。

等待连接和登录会持久化，连接恢复后继续；超过十分钟或等待期间正文、配置、已识别账号变化时停止旧任务。进程中断后只从原回执恢复结果，不重放发送步骤。人工确认平台未收到后，原未知回执可恢复为允许重试。

交付返回后只合并回执与保存时间，不覆盖交付期间继续输入的标题和正文。公众号和其他渠道同时交付时，单纯回执写回引起的时间变化不会被误判为正文冲突。

勾选小黑盒时，批量入口先补齐固定话题、社区与默认创作计划，再保存并绑定这份版本；重试保留已预留的第二社区、计划与封面，不重复制造手动版本。未选小黑盒时不修改这些设置。

删除草稿会取消尚未发送的批量任务，恢复草稿不会续发旧任务；正在发送的稿件需等结果返回再删除。已经完成或结果未知的回执保留。

结果按能力区分：

| 平台 | 当前结果边界 |
| --- | --- |
| 微信公众号 | 官方草稿接口；回读匹配后标为已核对 |
| 小黑盒 | 编辑页逐项填入与回读；不声称已经存入草稿箱或公开发布 |
| 百家号、知乎 | 同步助手报告草稿回执；不是远端独立内容核对 |
| 今日头条 | 只打开文章编辑入口，不计入自动存稿数量 |

## 任务不再只靠心跳保持运行

任务增加实际进度与总时限：默认十五分钟没有新进展，或处理超过四十五分钟，会记录可恢复失败并发出取消信号。自动租约心跳不能重置实际进度计时。旧执行器迟到的结果不能复活失败任务，超时任务不会自动重发。

取消信号已接入采集、中文讲解、素材图采集、事实核对、素材包、普通成稿、编辑入口成稿与导入成稿。模型调用可协作中断，关键存储提交再次检查取消状态。部分来源下载只在调用前后检查取消，不能承诺立刻终止第三方操作；旧执行器结束前保留并发占位。

修复来源健康误报：新闻源已读取成功之后，后续模型或图片步骤失败不再把新闻源标为连接故障；人工取消也不会污染健康状态。旧历史记录保持原样。

## 实际统计

只读接口：`GET /api/workflow/performance?days=30`，窗口支持 1–365 天。可附加最多一百个 `url` 参数，核对这些已知链接在本地采集路径中的去向，不会抓取输入网页。

本地报告：`node --import tsx server/workflow-performance-cli.ts`。输出不包含正文、图片字节或凭据，不调用模型、不更新事实分或表达偏好。

- 来源指标使用已保存的成功/失败路线与逐条路径；分开同轮链接去重和跨轮重复读取。没有逐条路径的旧运行不会补造数据。
- 时间指标表示“本地首次记录时间减去所声明的原始发布时间”，包含首次导入和历史积压，不等同于实时抓取延迟。索引时间、最后更新时间、只有日期的标题和无法识别日期的记录不进入此指标。
- 初稿指标只统计每个素材包的第一次生成结果，不用后来成功的重试美化首次质量门结果。
- 修改指标只使用 AI 初稿的首次、有效、未使用 AI 修改的人工确认；衡量按原顺序保留的完整段落，不冒充语义质量评分。缺少确认、旧基线不完整或无法判定人工修改的稿件单列排除。
- 没有真实漏报基准集时，实时漏报率为未知。

本机只读报告此次记录到近三十天 52 次采集，其中 34 次有逐条路径，22,682 行观察、3,149 个不同链接、18,608 次跨轮再次观察。人工确认修改的有效样本为零；目前不能据此宣称初稿已经改善。

已更新本机 `http://127.0.0.1:4317/` 服务与页面。更新前确认无运行任务或待处理交付，保留原静态资源备份与旧资源文件，服务就绪后原子切换页面入口。一篇现存草稿的完整内容/元数据指纹与二十一篇回收站的目录元数据前后一致。正式页面只读验收通过 1440px/390px、五个平台选项、无页面异常；浏览器检查拦截所有非 GET 请求，没有修改用户稿件。
