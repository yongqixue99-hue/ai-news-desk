# AI 新闻工作台浏览器助手

这是 AI 新闻工作台面向常用 Google Chrome 的本地助手，不依赖 Codex 或电脑操作 Harness。它提供两项能力：

- 在单条 X 原帖页面点击扩展图标，再点“一键收进新闻台”，只把规范链接交给工作台，由 X 官方 oEmbed 免费读取公开正文并进入证据复核；
- 把工作台中的文章或图文草稿填入小黑盒编辑器。

本地开发安装：

1. 在 Chrome 打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择当前 `chrome-extension` 文件夹。
5. 刷新 `http://127.0.0.1:4317/`。

扩展长期权限只覆盖本地工作台与小黑盒域名。X 收录必须由用户点击触发，借助 `activeTab` 仅读取当前标签页 URL，不注入 X 页面、不读取页面正文或 Cookie，也不在后台扫描时间线；平台分发只填入草稿箱或编辑器，不会点击最终发布。
