# OpenAI 更新 GPT-5.6：免费文字聊天取消常规次数上限

OpenAI 8 月 6 日宣布调整 ChatGPT 的模型阵容。Free 和 Go 用户的默认模型将在本周切换为 GPT‑5.6 Luna；从下周开始，文字聊天取消常规次数上限，并新增 **Think** 按钮，让用户在复杂问题上临时调用更强的推理能力。需要注意，“不限量”只针对文字对话，文件上传、图片、语音及其他工具仍有单独限额，同时受防滥用机制约束。

![ChatGPT 免费用户新增 Think 按钮](/Users/xueyongqi/Documents/ChatGPT/project-10/docs/prototype/openai-gpt-5-6-update/assets/01-free-think-button.jpeg)

*图：免费版新增 Think 按钮。图片由 OpenAI 提供，经 TechCrunch 报道页面获取。*

Plus 和 Pro 用户则获得更新后的 GPT‑5.6 Sol。它同时负责日常快速回答与深度推理，OpenAI 称新版回答更聚焦、事实可靠性更高；用户还可以用滑杆调节模型的思考强度。此次更新只进入 ChatGPT 对话体验，面向 Work 和 Codex 的 GPT‑5.6 Sol 暂未改变。

![Plus 和 Pro 用户可调节 GPT-5.6 Sol 的思考强度](/Users/xueyongqi/Documents/ChatGPT/project-10/docs/prototype/openai-gpt-5-6-update/assets/02-plus-pro-thinking-slider.jpeg)

*图：GPT‑5.6 Sol 思考强度滑杆。图片由 OpenAI 提供，经 TechCrunch 报道页面获取。*

OpenAI 公布的内部评测显示，在一组金融、医疗和法律提示词中，相比 GPT‑5.5 Instant，GPT‑5.6 Luna 出现至少一处事实错误的回答减少约 62%，GPT‑5.6 Sol 减少约 68%。这组数据来自厂商内部测试，且只覆盖特定题型，不能直接等同于独立基准中的全面领先。

这次更新最值得关注的并不是又多了两个模型名字，而是前沿模型的竞争正在从“榜单分数”转向“默认体验”：更强模型能否进入免费层、推理是否可控、使用门槛是否足够低。OpenAI 正在把推理能力做成普通用户随手可用的功能，但“不限量”目前仍只是文字聊天，不代表所有 AI 工具都已免费开放。
