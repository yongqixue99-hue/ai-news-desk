# 重要发布与原文图表改进

## 复现结果

用户反馈 GPT-6 Astra、Claude Fable / Mythos 的发布没有突出展示，并希望把官方文章里的能力图表带进草稿。

- GPT-6 发布已经被采集，但共用参考手册跨事件参与聚合，较早研究资料又参与事件日期计算，导致新发布被算成约 57 天前，退出今日推荐。
- Claude 发布保留了 Google News 中转 URL，官方原文条件没有满足，超过 48 小时后落入近期积压。官方 sitemap 实际包含直达发布页。
- 素材采集在本地已有两张图片时直接返回。静态提取漏掉部分懒加载、picture 和宽幅浅图；浏览器只检查 img，不能保存 SVG 图表或 HTML 评测表。
- 草稿生成把备选图库也限制在正文配图数内，其余图表没有进入编辑器图库。

## 已实现

1. StoryDesk 先聚合事件，再按明确的 evidenceGroupUrl 附加研究资料；研究资料不再连接多个事件，也不决定事件日期或主标题。原始记录与旧稿保留。
2. SourceDesk 用同一官方来源的 sitemap / feed 链接匹配明确的发布标题，保存 canonical_url，同时保留原始发现 URL 和日期。不把 sitemap lastmod 当成发布日，不凭标题拼造 URL。
3. 首页新增「近期重要发布」，回看七天官方发布线索，区分已定位原文、原文待核对、已进入写作；不会提高证据分或解除成稿阻断。nightly / canary 日常构建不进入该区域。
4. 素材包使用 article 收集模式，检查至多两篇优先事实来源，每篇最多 16 张原图和 8 张可见图表截图，Story 与冻结稿件图库最多 48 张。首页预览仍为轻量模式。
5. 提取 picture / srcset 较大版本和懒加载图片，优先正文图片，排除侧栏及关联文章。浏览器可截取包含图例、标题、说明的 SVG / Canvas 图表和 HTML 表格；错误页面、整站首屏不作为兜底图片。维持公开网络校验。
6. 正文按原配图上限编排，其余冻结图片以 afterParagraph=-1 进入「本稿配图库」。保留来源、SHA-256 与权利记录，不改写用户已有文章。
7. 阅读器分为「事件摘要」和「图片与图表」，支持大图、缩略图切换、完整图片、原文与本地下载；后台收集记录失败原因，显示素材缺口。素材包高级入口折叠，主动作仍为生成基础稿。

## 验证与边界

- `npm test`：640/640；`npm run eval:editorial`：22/22；构建与浏览器 E2E 通过。
- E2E 覆盖重要发布进入阅读器、图表切换、原文链接、收集刷新、部分失败提示和手机无横向溢出，也保留原有草稿恢复与存储限制检查。
- Anthropic 真实发布页获得 4 张原图、4 张图表截图，共 8 张本地素材；8 张通过素材包冻结和 SHA-256 校验进入草稿图库，示范正文放置 2 张，其余 6 张保留为备选。验证使用临时工作目录，没有生成模型正文、操作用户草稿或交付平台。
- 当前机器访问 OpenAI GPT-6 发布正文返回 HTTP 403；官方 RSS / sitemap 和 Google News 发现结果可读，已验证直达链接匹配。不能声称该页全部图片已经下载。
- 隐藏交互面板、分页、视频帧、登录内容以及访问受限页面不保证完整采集；不会绕过访问限制或用生成图替代事实图表。图片下载不代表发布授权，交付时继续执行既有权利检查。

下一步应在真实文章上校对图表与段落的相关性、图片数量和最终公众号排版，不增加无依据的热度或自动发布行为。
