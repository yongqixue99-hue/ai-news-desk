# 草稿基础管理 · 2026-09-22

草稿页固定显示“新建草稿”“删除当前草稿”“清空草稿”和“回收站”，空库也保留入口。新建会直接进入空白编辑器，无需先选新闻或调用 AI。仍沿用红白界面与原有编辑、版本和交付功能。

删除与清空均需在界面确认。清空范围是当前库中全部草稿（含历史旧稿），只影响本地草稿库；平台草稿不受影响。所有删除记录保存在 SQLite 的独立回收站片段中，正文、图片、证据、版本和回执不作清理，可逐篇恢复并打开。回收站随完整备份保留，跨系统迁移沿用原有路径及文件校验。

新建、删除、恢复前先保存当前修改；删除使用确认时的 ID 和版本列表，其他窗口修改过的草稿导致整批拒绝，确认后新产生的草稿不被误清空。旧保存不能重建已删除条目，恢复会更换版本时间以拒绝旧窗口覆盖。切换文章重置编辑区滚动，恢复后标题直接可见。
