# C2 新闻工作台提案 — 等待用户决定

本提案将采集条件收成一行、日期按需展开；候选从八列表格改为中文标题在前的行列表；桌面保留右侧待写区，手机在导航上方保留生成按钮。代码保持独立 PR 打开，不合并、不上线。

所有截图来自六条虚构候选、两条虚构待写选题与两个虚构采集来源。夹具只支持内存选择，其余采集、生成、交付和发布写接口均拒绝，不启动数据库、工作器或模型。固定示例时间为 2026-10-07，不是用户当日数据。

## 保留的行为

排序、评分、入选及证据状态未改变；候选仍代表单条来源，优先区明确说明候选级排序与 48 小时窗口。原题、链接、来源、图片状态、偏好操作、筛选、清理、失败重试、运行追溯和快速收录保留；J/K、A/空格、G、/ 的原处理逻辑保留。页面没有添加最终发布行为。

日期输入与原校验仍在折叠区，日期不合法时概要显示提示图标，采集按钮仍禁用。手机待写面板是普通页面区域，不是覆盖候选的弹窗；底条展开后滚到面板，两个收起入口同步。正文末尾预留空间，最后一条原文操作和底部导航不会被遮挡。

## 验证与权衡

组件测试先失败后实现，所有原测试保留；浏览器覆盖三个尺寸、折叠日期与无效范围、生成数量、原文链接、手机移除与收起、导航、搜索快捷键、溢出和控制台错误。指标与截图生成脚本见 [measurements.json](measurements.json) 和 `scripts/ui-preview/workbench.mjs`。

手机常驻操作条占用约 58px，但省去滚到页面末尾生成的操作；桌面的日期改成展开操作。是否采用这个信息分布由用户看过效果后决定。
