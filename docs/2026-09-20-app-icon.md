# 应用图标与下一步优化（2026-09-20）

## 图标

以现有红白品牌为基础，使用新闻页、折角与 N 字形。可编辑母版在 `public/brand/news-desk.svg`；运行 `npm run assets:icons` 使用现有 sharp 生成 PNG、浏览器 ICO、Windows ICO 和 Mac ICNS，不访问外部服务。

- 网页：标签图标、Apple Touch 图标和侧栏标记统一。收起侧栏时仍保留展开按钮提示。
- Mac：构建脚本将 `AppIcon.icns` 放入应用 Resources，并在 Info.plist 声明。已有应用重新运行 `scripts/build-mac-app.sh` 后退出再打开。当前用户的 `~/Applications/AI 新闻台.app` 是 `/Applications/AI 新闻工作台.app` 的链接，保持原路径和 Spotlight 入口。
- Windows：生成的桌面快捷方式设置 `desktop/assets/app-icon.ico`。更新代码后双击根目录启动入口即可重新保存快捷方式；本次没有把 Edge/Chrome 应用窗口变成独立 Windows 原生安装包，其任务栏归属仍由浏览器管理。
- 图标资源随代码分发，首次启动不需要图像生成工具。不改变稿件、数据库或凭据。

## 建议优先级（尚未实施）

1. **连接诊断。** 明确区分未配置、等待扩展、地址不匹配、Token 无效、平台未登录和接口权限不足；连接状态自动更新。微信白名单错误提供接口实际检测到的 IP 及复制入口。当前通用“等待连接”会掩盖配置已保存但桥接未建立的区别。
2. **真实交付验收。** 公众号白名单处理后验证一次新建草稿及原位更新；知乎核对真实远端正文与图片；百家号先解决助手缺少稳定账号 ID，再开放投递。账号检查通过不能算文章送达，保持现有失败闭锁和幂等回执。
3. **热点覆盖验收。** 用用户实际关注的热点建立漏报清单，观察首次发现延迟、重复合并和前排推荐质量；同时给出平台排序与汇总排序依据。先验证已有源的效果，再决定补哪些源。
4. **桌面维护。** 提供清楚的版本号、更新提醒、连接修复入口及 Windows 实机验收。升级保留草稿和凭据；当前双击启动入口还不是带自动更新的完整安装包。

以上是真实使用反馈导出的后续工作，不代表本次已完成这些功能，也不改变人工最终发布的产品边界。

1091 项测试、编辑质量黄金集 22/22、TypeScript 检查和生产构建通过。ICNS 经 macOS `iconutil` 成功解包，ICO 包含 16–256 像素的七档尺寸。Mac 应用重新构建、签名验证并实际启动，侧栏图标显示正常；本机静态图标返回 HTTP 200。Windows 快捷方式已接入 ICO，实机视觉效果仍需 Windows 验收。
