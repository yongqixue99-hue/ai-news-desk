# 2026-09-05 选题策略与 Tab 续写

本轮针对三个实际问题：推荐混入活动与常规动态、内容策略页面看不出配置是否参与运行、Tab 续写缺少即时控制且会重复请求。沿用个人本地编辑台和现有稿件流程，未增加新的发布渠道。

## 已实现的变化

### 选题：重要变化与有趣实践分开

- 默认 `focused` 精选；`balanced` 保留广泛浏览。今日最多展示 8 条，其中有趣实践最多 2 条；没有足够合格题材时保留空位。
- 明确的发布、价格变化、服务故障、安全事件和产业变化优先；实测、教程、复现、老游戏移植、作者展示项目等可以在热度未知时进入有趣实践。
- 报名、汇总、例行构建和带传闻措辞的标题默认退回全部候选。精选观察区遵守相同规则，招聘等常规线索不会从这里重新冒出。用户已选择或明确感兴趣的条目保留人工覆盖路径，证据门槛继续独立执行。
- `server/newsworthiness.ts` 提供确定性的选题提示与理由，不预测阅读量。调整展示顺序时不修改存储的事实分或热度分；降低图片数量对排序的影响，避免图片多的次要消息占优。
- Today 现在读取最近 30 天明确反馈；长期关注主题启用时只增加轻微的排序调整。分别关闭后停止应用，历史记录保留。
- 修复 `launches / announces / introduces` 等标题变体没有加入同一模型发布的问题，保留原 Story 身份与独立后续事件。官方指南、研讨会不能因正文提及模型已经可用而升级为重要发布。
- 现有七天官方模型发布入口与证据补齐仍保留。有趣实践也进入首页最多五条的后台素材补齐队列。

### 内容策略：展示真实用途与状态

页面由选题、文章怎么写、Tab 续写和自动读源组成。主要写作字段缩为内容定位、读者和表达偏好；更多约束、来源列表、记忆依据、建议和规则检查默认折叠。桌面使用主栏与侧栏，手机使用单栏。

| 控件 | 实际作用 | 关闭后的行为 |
| --- | --- | --- |
| 推荐范围 | 今日和新闻工作台的精选范围 | 可切换广泛浏览 |
| 参考选题反馈 | 参考明确兴趣调整展示顺序 | 停止应用，保留反馈 |
| 应用写作档案 | 组织下一次成稿与补全的定位、读者、表达 | 不传入档案，保留已填内容 |
| 应用写作记忆 | 达到 5 次有效手动修改后应用启用的偏好 | 暂停应用，继续保留记录和单条设置 |
| 启用 Tab 补全 | 前端请求和后端接口共同检查 | 清除当前建议并停止请求 |
| 每日自动读源 | 复用既有本地定时采集 | 停止定时触发，仍可手动读取 |

写作档案以前只被保存和展示，本轮通过 `editorialProfileForWriting` 接入生成器与补全提示词。它只组织语言，不成为事实证据，也不会改写已编辑的旧稿。编辑质量规则不是可关闭的表达偏好。

验收时用户状态：精选开启、选题反馈开启、Tab 开启；写作档案为空，页面说明填写并保存后才应用；写作记忆为 **3 / 5**，页面说明当前尚未用于写作。自动读源仍是每天 22:30，22 个选入来源。未替用户填入虚构定位。

### Tab：可主动请求，也能安静退出

- 编辑器新增“Tab 续写 · 开 / 关”和“续写一次”。策略页显示当前模型、密钥或模型缺口；“配置就绪”不冒充实际请求成功。
- 中文输入法组合输入期间取消请求并禁止采纳；Shift+Tab 等组合键不会误采纳。没有建议时不接管普通 Tab。
- Esc 忽略后的同一上下文不再自动重试；无建议结果也短暂缓存在当前编辑器中，手动请求可重新尝试。
- 保留请求取消、过期响应隔离、短建议预览、Tab 分段采纳、Ctrl+Enter 全部采纳及撤销。进入预览、切换稿件或关闭补全时清除建议。
- 当前上下文包含光标前最多 1,600 字符和后最多 500 字符；后文也参与重复与未覆盖事实判断。仍是有界上下文和确定性数字、实体检查，不是整篇文章的语义证明。
- 用户档案与已解锁的写作记忆放在非证据偏好区；事实继续来自冻结的 `ContentPackage`。保留 X / Gemini 原有支出规则，不更改用户当前 DeepSeek 选择。

## 后续优先级

1. **先缩短发现延迟。** 现在每天读取一次，即使排序正确，也可能迟一天才看到发布。重点官方源应单独设置较短巡检周期，尊重来源限流与失败退避；普通媒体和社区采用较低频率，并显示最近成功读取时间。本轮尚未增加这条调度能力。
2. **建立真实漏报账本。** 为一批人工确认的重要事件记录官方发布时间、首次发现、进入推荐时间及漏报环节：没有抓到、抓到但未识别、被聚合错、证据未就绪、排序未展示。用真实事件验证后再调整规则，不能用合成测试的通过率充当命中率。
3. **把兴趣反馈分清原因。** 后续可增加不重要、已看过、太晚、重复、想继续跟进等原因，避免一次忽略就压低整个来源。有趣但暂时不写的题材可进入明确的灵感收藏，当前仍通过感兴趣和待写保留。
4. **验证内容吸引力。** 继续真实文章试用，比较用户最终采纳的选题与修改；标题突出可核实的变化、反差和使用场景。阅读量反馈要与事实评分分开，不能为追逐热度扩大未经支持的结论。

来源原图、图表和截图链路继续沿用上一轮实现。官方页面访问失败仍是独立来源缺口，不因本轮页面美化或推荐调整而自动解决。微信草稿同步和手动发布合同保持不变。
