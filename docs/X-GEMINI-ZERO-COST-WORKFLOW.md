# X 与 Gemini 零新增支出操作手册

这套流程只约束两类额外费用：X API 与 Gemini API。DeepSeek、通义、OpenAI API 和其他模型保持原配置；是否使用、是否产生费用，由各自的启用状态决定。

## 一、一次性确认费用边界

1. 打开 AI 新闻台，进入左侧“AI 设置”。
2. 在页面顶部找到“X / Gemini 零新增支出”。
3. 保持“X / Gemini 已锁定”。此状态会在服务器端阻止 X API 和 Gemini API，不只是把按钮变灰。
4. 向下查看 DeepSeek。它不会被这个开关锁定；如果已经配置为 Tab 补全，仍可继续使用。
5. 已保存的 X Token 或 Gemini Key 不会被删除。以后确实需要接口时，可以显式切换到“允许 X / Gemini API”，但切换本身不会自动启用来源或模型。

## 二、免费监控 X

### 第一次建立私人列表

1. 进入左侧“新闻源”。
2. 找到最上方“X 免费监控（人工接力）”。
3. 点击“复制重点账号”，得到当前项目维护的重点账号清单。
4. 点击“打开 X 列表”，登录你自己的 X 账号。
5. 在 X 中新建一个列表，例如命名为“AI 一手消息”，并设为私人列表。
6. 按复制出的清单逐个搜索并加入。X 通常不支持一次性批量粘贴；可以先加入下列最高优先级账号，再逐步补齐其余账号：
   - `@OpenAI`、`@OpenAIDevs`
   - `@AnthropicAI`、`@claudeai`
   - `@GoogleDeepMind`、`@GoogleAI`、`@GeminiApp`、`@GoogleAIStudio`
   - `@deepseek_ai`
   - `@Alibaba_Qwen`
   - `@xai`、`@AIatMeta`
7. 对极重要的少数官号，可在各账号主页打开 X 自带的新帖通知；其余账号集中在私人列表中查看，避免通知过载。

### 每次看到重要帖子时

1. 先确认账号 handle 与官方身份，不只看头像或认证标记。
2. 点击帖子的分享按钮并复制原帖链接。链接必须包含 `/status/帖子编号`。
3. 选中并复制原帖全文；如果是串文，按原顺序一起复制。
4. 回到 AI 新闻台，进入“新闻工作台”。
5. 点击“截图／链接成稿”，切换到“X 原帖”。
6. 粘贴原帖链接和正文；账号栏可留空，系统会从链接识别，也可手动填写 `@账号`。
7. 点击“提取并复核”。
8. 在证据复核页检查账号、链接、正文和上下文，再确认生成草稿。
9. 若帖子只是预告、个人判断或跑分截图，继续寻找官网公告、文档或独立媒体，不能把它自动写成公司已确认事实。
10. 若帖子带图，优先保存官方原图；无法可靠下载时保留原帖截图。图片仍需在发布前检查来源与使用权。

该流程不调用 X API，不读取私信，不保存 X 登录 Cookie，也不会自动点赞或发帖。

## 三、使用现有 Google 账号在 Gemini 网页版协作写稿

1. 在“草稿”中打开要继续写的文章。
2. 先按 `Ctrl+S` 保存当前版本，确保修改前版本可恢复。
3. 打开右侧“Agent”面板。
4. 找到“用 Gemini 网页版协作写稿”。
5. 点击“复制证据写作提示词”。提示词会包含当前正文、来源链接、事实账本和待核对项，不包含图片二进制或本机密钥。
6. 点击“打开 Gemini”，使用你现有的 Google 账号进入网页版。
7. 粘贴提示词并发送。无需配置 Gemini API Key。
8. 复制 Gemini 返回的标题和正文，回到本地编辑器。
9. 优先按段落选择性替换；不要在未检查时一次性覆盖你已经编辑好的全文。
10. 对返回内容中的日期、数字、价格、跑分、引语和人物身份，回到右侧“资料”逐项核对。出现 `【待核对：……】` 时先补证据，不要直接删除标记。
11. 再按 `Ctrl+S` 保存，通过版本历史保留本次修改。

工作台不会接管 Google 登录、转存浏览器 Cookie 或自动读取 Gemini 回复。人工复制多一步，但稳定、透明，也不会产生新的 Gemini API 账单。

## 四、DeepSeek Tab 补全不受此开关影响

1. 进入“AI 设置”，查看 DeepSeek 是否已配置，以及是否标记为“正在补全”。
2. 打开一篇有 `ContentPackage` 事实包的草稿并开始编辑。
3. 停顿后如果出现灰色建议，按 `Tab` 接受下一段建议，按 `Esc` 忽略。
4. DeepSeek 属于单独的 API 调用，费用与限额以你的 DeepSeek 账号为准；“X / Gemini 零新增支出”不会替你关闭它。

## 五、出现问题时先检查什么

- X 原帖无法导入：确认链接属于 `x.com` 或 `twitter.com`，且包含 `/status/`；正文至少 10 个字符。
- X 自动来源显示停用：这是零新增支出策略的预期结果，使用上方人工接力入口。
- Gemini 按钮不可用：不要配置 API，直接使用草稿 Agent 面板中的“打开 Gemini”。
- DeepSeek 没有灰字补全：检查 API Key、补全模型和“用于补全”状态；这与 X/Gemini 费用锁无关。
- 网页生成内容出现新事实：不要直接发布；把该事实标为待核对，并补充一手来源。
