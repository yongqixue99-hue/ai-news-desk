# AI 新闻台全量优化交付记录

日期：2026-08-13  
本地地址：<http://127.0.0.1:4317/>

## 本轮完成

### 1. 采集与筛选

- 官网母站与后台栏目路由分离，支持综合、AI、科技、游戏、电竞、政治、商业和科学频道。
- 支持日期范围、关键词、来源组合、来源健康、批量维护、单源测试、清空候选和明确的“查看原文”。
- 传播信号只在来源能提供公开互动时使用真实数据；其他来源显示“传播参考”，不冒充阅读量。
- 候选可标记感兴趣或不感兴趣。历史偏好有上限、可解释、可恢复、可关闭和清空，只参与综合推荐排序。

### 2. 截图与链接成稿

- 链接或截图先进入 Evidence Review，不再直接黑箱生成。
- 保留原始输入、清洗后的正文块、被排除的噪声、真实图片或截图裁区及采集方法。
- 用户确认保留文字和图片后才能进入成稿；无 OCR 正文、未确认或空正文会被阻止。

### 3. AI 工作台

- 成稿、文章分析、文章优化使用三个独立模型插槽。
- Codex CLI、千问、DeepSeek、OpenAI 和兼容接口均有安全连接测试。
- 每次成稿、分析、优化和追问记录脱敏的 Provider、模型、Skill 指纹、耗时、错误类别、重试与回退；未发生的重试或回退不会伪造。
- API Key 继续存放在 macOS 钥匙串，不进入工作流状态或浏览器响应。

### 4. 草稿与图片

- 连续富文本编辑、光标插图、对照预览、版本恢复、自动保存和草稿生命周期已接通。
- 发布准备只检查正文中实际插入的图片，不会因为资料区中未使用的图片阻止发布。
- 素材保存版权状态、来源、证据、平台范围、有效期、实体标签和 SHA-256 指纹。
- 发布确认后只能逐图人工入库；必须由同一次填入回执确认图片被使用，并通过路径、文件、版权和重复检查。

### 5. 小黑盒填入

- 默认使用日常 Chrome 扩展；CDP 仅保留为调试备用。
- 填入前检查扩展协议、连接、登录、编辑器、标题、正文、图片、图注、分区和话题。
- 回执只有 filled、partial、blocked、failed；任何缺失都不会伪装成成功。
- 系统只填入编辑器，最终“发布”必须由用户在小黑盒点击。

### 6. 可靠性与体验

- URL hash、浏览器前进后退、非法路由回退、跳到主要内容、焦点环绕与移动端入口已补齐。
- 通知中心只点击展开，支持未读、单条已读、全部已读、Escape、焦点恢复和移动端。
- 自动化页增加工作流 JSON 校验备份、恢复和存储占用；媒体与素材目录明确作为随行文件。
- 编辑器已拆包，生产构建不再出现单个超大 DraftWorkspace chunk 警告。

## 仍然有意保留的边界

- 微信公众号和小红书目前只保留平台入口，不宣称已经接通。
- 平台验证码、登录失效和网站改版会停止流程，不绕过平台限制。
- 通知依赖本地服务运行，不是云端推送。
- JSON 备份不内嵌二进制图片；完整迁移仍需复制 `.workflow/media` 与 `.workflow/materials`。
- ChatGPT 登录可供本机 Codex CLI 使用，但不是通用 API。服务器或多人部署应配置正式模型 API。
