## 真实失败与修复

原任务 job_d91297f8-003b-4d1a-ad90-db040b5779c8 对应 Introducing ChatGPT Images 2.5，原始 URL 为 https://openai.com/index/introducing-chatgpt-images-2-5 。

复现时，原来的 AI-News-Desk 请求标识返回 HTTP 403。精确 URL 没有可复用正文快照。相同公开 URL 使用兼容的标准页面请求，返回 HTTP 200，提取出 8,237 个正文字符、61 个结构块。没有更改凭据、登录或页面访问权限；真实 403 仍返回错误。

修复 fetchArticleDocument 的请求兼容性，保留地址检查、响应体限制与真实错误。正文可读性/事实核对提前到配图处理之前，正文不可读时不再继续耗时准备图片。只有官方标题和摘要时，不再宣称“证据足够”，而是说明原文待读取。401/403/404 不自动反复重试；临时服务错误仍走已有有界重试。

失败选题自动保留。POST /api/product/jobs/:jobId/retry 只允许失败的 build-content-package 任务，为恢复任务生成独立幂等键并关联 retryOf；原失败历史不覆写。面板显示完整错误折叠项、重试读取、回到选题和完成后的继续写作入口。

另一复现问题：页面初始化使用 runs[0]，导致后台 evidence-supplement 出现在新闻工作台。选择规则现在默认取正常采集，显式历史选择仍保留。实机复验显示正常采集的 6 个候选，而不是先前补证记录中的单一 Gemini 条目。
