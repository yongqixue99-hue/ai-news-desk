# 微信公众号草稿交付验收

日期：2026-08-26

## 产品边界

- 目标账号是用户自己的微信公众号。
- 系统只执行只读连接检查、新建草稿和更新已有草稿。
- 没有发布、群发、定时群发或绕过人工预览的接口。
- 最终预览与发布必须由用户在微信公众平台完成。

## 已实现

- “定时任务”页增加公众号名称、默认作者、AppID、AppSecret、本地保存、移除密钥和只读连接测试。
- AppSecret 只写入 macOS 钥匙串；状态文件和导出备份只保存配置状态与脱敏提示。
- 文章“发布”面板可在小黑盒与微信公众号之间切换。
- 微信面板显示首张正文图封面、作者、摘要、原文链接、事实证据与图片许可检查。
- 正文图片先在本地转为 JPG、缩到最长边不超过 1600 px，并压到 1 MB 内，再上传为微信正文图；首图另存为封面永久素材。
- 首次同步使用草稿新增接口；已有回执时使用同一 `media_id` 更新；内容和图片指纹未变化时跳过网络写入。
- 同步回执记录本地草稿版本、微信 `media_id`、内容哈希、图片数量和封面图片，文章修改后会显示“微信草稿落后于本地内容”。
- 图片素材库与草稿图片治理均可分别记录小黑盒和微信公众号授权范围。

## 安全与失败处理

- 连接错误会把 IP 白名单、AppID、AppSecret 和接口权限问题转成可操作中文提示，不返回微信上游响应正文。
- AppSecret 和 access token 不进入日志、回执或前端状态。
- 微信同步只读取 `.workflow/media` 下的受管草稿图片，并同时检查真实路径，阻止可编辑状态或符号链接读取目录外文件。
- 图片权限待确认、授权到期、平台范围不含 `wechat`、本地文件缺失、事实待确认或证据不足都会阻止同步。

## 验证结果

- `npm test`：168 项通过。
- `npm run build`：TypeScript 与 Vite 生产构建通过。
- API 失败路径：非法 AppID 返回 400；公众号未配置时同步返回 400，未发生外部写入。
- Playwright：1440×1000 桌面端与 390×844 手机端完成设置页、微信发布面板和滚动状态检查；浏览器控制台无 error。

## 需要用户完成

1. 在微信公众平台取得自己的 AppID 与 AppSecret。
2. 把当前出口 IP 加入公众号 IP 白名单。
3. 在本地设置页填写并测试，不要把 AppSecret 发到聊天中。
4. 用一篇真实文章同步到草稿箱，登录微信公众平台检查微信实际排版、图片和封面裁切，再决定是否发布。
