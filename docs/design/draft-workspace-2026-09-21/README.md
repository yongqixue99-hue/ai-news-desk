# 草稿模式：正文优先

沿用当前红白风格与全局导航。首页、聚合资讯、新闻工作台和社区页面不在本轮改动范围内。

## 界面与交互

- 桌面宽屏默认打开草稿库；按最近修改排序，可搜索标题和所有来源名，筛选待处理、待交付或已交付稿件。已搁置的历史稿件仍需主动展开。
- 标题放回正文稿纸，随内容和窗口宽度自动换行；编辑区域限制为可读宽度，图片保持比例，不再横向铺满整个窗口。
- 保存和确认状态集中在顶栏；事实待确认事项保持可见，质量检查明细按需展开。修订标识与详细确认时间移入版本面板。
- 编辑、对照、预览位于正文上方；对照时自动收起两侧工具，预览保留排版主题选择。辅助工具命名为 AI 助手、资料、图片、版本、交付。Gemini 网页协作入口收为可展开区块。
- 移动端草稿库和辅助工具互斥显示，抽屉停在工具栏上方，保存按钮不再与状态、通知按钮重叠。
- 交付仅打开既有平台草稿流程；公众号、社交同步助手和小黑盒的设置入口直接定位对应连接表单。

自动保存、安全切稿、版本恢复、冻结事实、AI 精确补丁、图片权利和交付检查沿用现有模块。没有改写用户真实稿件，没有调用模型、采集或平台投递接口进行界面验收。
