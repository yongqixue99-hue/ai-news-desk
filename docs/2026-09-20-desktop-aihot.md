# 双击应用与 AIHOT 接入（2026-09-20）

## 日常入口

Mac 本机应用安装在 `~/Applications/AI 新闻台.app`，双击进入独立 WebKit 窗口。可拖到 Dock。仓库中的 `启动 AI 新闻台.command` 可生成／打开应用（生成需要 Xcode Command Line Tools）；应用指向当前项目，项目移动后须重新运行 `scripts/build-mac-app.sh`。这不是包含全部运行环境的独立安装包，不要删除原项目目录。

Windows 更新 main 后，双击仓库根目录的 `启动 AI 新闻台.cmd`。首次自动查找 Node 22.16+，缺失时从 nodejs.org 官方下载 Node 22 便携版并校验 SHA-256，再安装依赖和构建；需要网络和几分钟等待。成功后创建桌面 `AI News Desk` 快捷方式。优先使用 Edge/Chrome 独立应用窗口，缺失时打开默认浏览器。日常无需终端命令；第一次准备会显示进度窗口。当前用户策略若禁止执行本地 PowerShell，需管理员处理组织策略，脚本不修改机器级安全策略。

已安装的 Windows 同项目计划任务可自动重启升级；其他工作区或不明程序占用 4317 时停止并解释，不结束陌生进程。未装计划任务时按需启动，不自动安装开机任务。重复打开复用当前服务；关闭窗口保留后台任务。未打包自动更新器，代码更新仍通过 main，首次切换到本版后按本项目现有服务流程维护。

应用继续使用原 `.workflow` 与 Keychain/DPAPI，不迁移、不清空、不上传数据；新 Windows 克隆没有 Mac 的稿件和密钥。迁移须使用已有的归档预检和事务导入。

## 新闻发现

- AIHOT.news：使用官方 `https://aihot.news/feed.xml`（精选）与 `/feed/all.xml`（近期动态），无需 Key；保留摘要、AIHOT 聚合页、出版方原文及索引日期。来源角色固定 discovery，不能把聚合摘要当已核实事实，不抓取其聚合全文。
- aihot.cn：HTTPS 连接失败、HTTP 502；尚不能证明与 AIHOT.news 同站。注册为停用的“待确认”入口，不声称已接通，不猜测 RSS 地址。
- 根据 AIHOT [接入说明](https://aihot.news/agent)，RSS 建议至少 30 分钟间隔，个人本地阅读允许；对外镜像和商业再分发不在本实现范围。
- 原“官方来源增量检查”扩展为“官方与热点增量检查”：同时轮询已启用且已选中的 RSS/Google News discovery 来源。沿用用户开关和 30/60/120/240 分钟间隔，默认 60 分钟，连续失败指数退避；技术目录仍 12 小时。采集只加入候选，不自动成稿，不承诺完整全网覆盖。
- 上一轮 Jev 通用搜索修复随本次提交交付：独立 Bing RSS 备用路线、旧大厂限定查询兼容、引号关键词识别、部分读取失败提醒。
